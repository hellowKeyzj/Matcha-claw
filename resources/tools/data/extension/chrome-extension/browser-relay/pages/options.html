Quick start
  1. Make sure MatchaClaw is running with browser control enabled.
  2. The relay connects automatically. A green dot means the encrypted handshake is ready.
  3. Select a window in the extension, then ask MatchaClaw to work with its current page.
How it works
Automatic connection
The relay connects automatically when enabled and MatchaClaw is running. Use the popup toggle to pause it.
Automatic reconnection
If the connection drops, the extension reconnects automatically.
Tab safety
Only agent-created tabs can be closed by the agent. Retained tabs and temporarily claimed personal tabs stay protected.
Status indicators
Encrypted relay ready — the selected window’s current page can be controlled Connecting or completing the encrypted handshake Relay disabled — no indicator
Troubleshooting
The dot stays yellow
Make sure MatchaClaw is running with browser control enabled and the relay port matches.
A page does not respond
Internal Chrome pages (chrome://) cannot be controlled. Open a regular webpage.
